# Project Overview

## Mission

Build a performant, secure, and accessible decentralized blockchain for global value transfer.

## Architecture

- Daemon: C++20, JSON-RPC interface (HTTP 8545)
- Backend services: Node-based helper services (market feed, API gateway)
- Packaging: Docker (dev/prod), native builds (Windows/Linux)

## Roadmap

- Q1: Mainnet hardening, monitoring, and snapshots
- Q2: Exchange listings and explorer integrations
- Q3: Ecosystem tools and SDKs
