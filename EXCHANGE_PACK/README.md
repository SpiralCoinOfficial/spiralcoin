# Exchange Listing Pack

This folder contains materials commonly requested by Tier-1/2 exchanges.

## Contents

- PROJECT_OVERVIEW.md: Mission, architecture, roadmap, links
- TEAM_CONTACTS.md: Team bios and listing POCs
- TOKENOMICS.md: Supply, emissions, circulating plan
- RISK_DISCLOSURES.md: Operational risk overview
- SECURITY.md: Security policy, past audits
- GOVERNANCE.md: Upgrade/consensus governance
- RPC_API.md: API endpoints and examples
- BRAND_GUIDE.md + /assets: Logos and brand assets (SVG/PNG)

Add jurisdictional legal opinion, KYB, AML/CFT policy, sanctions controls, and privacy policy as separate documents or links.
