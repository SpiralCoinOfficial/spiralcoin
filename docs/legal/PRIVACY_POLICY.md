## 1. INTRODUCTION

SpiralCoin Foundation, LLC ("Company", "We", "Us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and secure your personal information when you use our platform at https://spiralcoin.net and related services.

## 2. INFORMATION WE COLLECT

### 2.1 Information You Provide Directly

**Account Registration:**
- Email address ✓ (required)
- Full name (optional, recommended for support)
- Phone number (optional)
- Password (hashed, never stored in plaintext)

**Trading & Transaction Data:**
- Wallet addresses (both your own and transaction recipients)
- Transaction history and amounts
- Order history (buy/sell orders, prices, quantities)
- API keys and tokens (if developer account)

**Customer Support:**
- Support ticket content and attachments
- Communication history with our team
- Screenshots and technical logs (if provided)

**KYC/AML Verification** (future feature):
- Government-issued ID (passport, driver's license)
- Proof of address (utility bill, bank statement)
- Source of funds declaration

### 2.2 Information Collected Automatically

**Technical Data:**
- IP address and geolocation (inferred from IP)
- Device type, OS, and browser information
- Cookies and session identifiers
- Referrer URL and access timestamps
- API call logs (endpoint, method, timestamp, response code)

**Usage Analytics:**
- Pages visited and time spent on each
- Features used (trading, wallet, API access)
- Market data requests and search queries
- Error logs and crash reports

**Blockchain Data:**
- Transaction records (immutable, permanently recorded on blockchain)
- Wallet balance and activity (public on blockchain)
- Smart contract interactions (recorded on-chain)

### 2.3 Information from Third Parties

- **Payment processors**: Card issuer fraud checks, payment status
- **Email verification services**: Email validity confirmation
- **IP geolocation providers**: Country/region from IP address
- **Blockchain explorers**: Public transaction verification
- **Law enforcement**: Subpoenas or court orders for user information

## 5. WHO WE SHARE YOUR DATA WITH

### 5.1 Data Sharing

**We DO NOT sell your personal data to third parties.**

We may share data with:

1. **Service Providers**:
   - Hosting & cloud providers (AWS, Azure, DigitalOcean)
   - Email delivery services (SendGrid, etc.)
   - Analytics platforms (Mixpanel, etc.)
   - Payment processors (Stripe, PayPal, etc.)
   - KYC/AML verification vendors (Chainalysis, Coinfirm, etc.)

   *All service providers sign Data Processing Agreements ensuring GDPR compliance.*

2. **Legal/Regulatory Authorities**:
   - Law enforcement upon valid court order or subpoena
   - Regulatory bodies (SEC, CFTC, FinCEN, etc.)
   - OFACs sanctions screening (automated, government lists)

3. **Business Partners**:
   - Exchange partners (information shared to enable trading)
   - Liquidity providers (anonymized usage data)
   - Audit firms (during security or financial audits)

4. **Public Blockchain**:
   - Transaction data is **permanently recorded on the SpiralCoin blockchain**, which is:
     - Immutable (cannot be deleted)
     - Publicly viewable by blockchain explorers
     - Linked to wallet addresses (not directly to names, unless you publish them)

### 5.2 Data NOT Shared

**We retain and do not share:**
- Account passwords (hashed one-way)
- API keys and secrets
- Private wallet keys (users hold these, we never store them)
- Support ticket contents (shared only with relevant support staff)

## 6. DATA RETENTION

| Data Type | Retention Period |
| --- | --- |
| Account information | Until account deleted + 90 days |
| Transaction history | Permanently (blockchain is immutable) |
| Login logs & IP addresses | 12 months |
| Support tickets | 3 years (for dispute resolution) |
| API access logs | 90 months (7.5 years, regulatory requirement) |
| Cookies & session data | Until browser closed or cookie expiration |
| KYC/AML documents | 5 years (regulatory requirement) + 30 days deletion request |

**Account Deletion**: You may request account deletion by emailing support@spiralcoin.net. We will delete:
- Email, name, password hash
- API keys and session tokens
- Support tickets and preferences

**We cannot delete**: Transaction history (blockchain is immutable) or historical logs already archived for compliance.

## 8. SECURITY MEASURES

### 8.1 Data Protection

We implement:
- **TLS/HTTPS encryption** for all data in transit
- **AES-256 encryption** for sensitive data at rest
- **bcryptjs password hashing** with salt (10 rounds minimum)
- **Hardware security modules (HSM)** for key material (future)
- **Rate limiting & DDoS protection** via Cloudflare
- **Web Application Firewall (WAF)** to prevent injection attacks
- **Regular security audits** and penetration testing

### 8.2 Access Controls

- **Principle of least privilege**: Employees access only necessary data
- **Role-based access control (RBAC)**: Admin, support, developer roles
- **Audit logging**: All access logged with timestamp and purpose
- **Multi-factor authentication**: Available for sensitive accounts

### 8.3 Limitations

**No system is 100% secure.** While we use industry-standard protections, we cannot guarantee:
- Prevention of all breaches
- Absolute security of data in transmission
- Protection against state-sponsored attacks

## 9. YOUR DATA RIGHTS

### 9.1 GDPR Rights (EU Residents)

If you are in the EU, you have the right to:

1. **Access**: Request a copy of your personal data (portable format)
2. **Rectification**: Correct inaccurate information
3. **Erasure**: Request deletion ("right to be forgotten") — *with limited exceptions*
4. **Restrict processing**: Limit how we use your data
5. **Portability**: Export data in a standard format
6. **Objection**: Opt-out of profiling, marketing, or legitimate interest processing
7. **Withdraw consent**: Stop consent-based processing (e.g., marketing emails)

**To exercise rights**: Email privacy@spiralcoin.net with your request. We respond within 30 days.

### 9.2 CCPA Rights (California Residents)

If you are in California, you have the right to:

1. **Know**: Request what data we collect
2. **Delete**: Request data deletion (with exceptions)
3. **Opt-out**: Opt-out of data sales (we don't sell, but you can opt-out of analytics sharing)
4. **Non-discrimination**: No penalty for exercising rights

**To exercise rights**: Visit our account settings or email privacy@spiralcoin.net.

### 9.3 Data Subject Access Requests (SARs)

To request a copy of all your data held by SpiralCoin:
1. Email privacy@spiralcoin.net with subject "Data Subject Access Request"
2. Provide proof of identity
3. We deliver data within **30–45 days** in a portable format (JSON/CSV)
