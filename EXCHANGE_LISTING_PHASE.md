## 🏢 Regulatory Considerations

### Legal Entity

**Recommended Structure**:
```
Singapore - ACRA Registration
- Pro: Crypto-friendly
- Tax: 5% corporate tax rate
- Regulation: Clear regulatory path

OR

Switzerland - Canton Zug
- Pro: "Crypto Valley"
- Tax: Favorable
- Regulation: FINMA guidelines

OR

Malta - MFSA License
- Pro: EU-compliant
- Regulation: Well-regulated
- Tax: Competitive
```

### Compliance Steps

```
1. Register company entity
2. Get tax ID / VAT number
3. Money laundering compliance (AML/KYC)
4. Legal opinion on token status
5. Prepare regulatory filings
6. Document everything for exchanges
```

### Token Classification

**Key Question**: Is SPIRAL a security?

**Securities Analysis**:
```
Howey Test (US):
1. Investment of money? YES
2. Common enterprise? YES
3. Expectation of profit? YES (typically)
4. Efforts of others? YES

→ May be classified as security

Solutions:
1. Utility token design (voting, gas payment)
2. No profit expectations in terms
3. Governance utility proven
4. Regional compliance (Singapore/Switzerland)
```
