                          TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Compiler not found
Solution:
  • Check MinGW installed: C:\msys64\mingw64\bin\g++.exe
  • Or use Docker (doesn't need local compiler)

Problem: CMake configuration fails
Solution:
  • Use DIRECT_BUILD.bat (skips CMake)
  • Or use DOCKER_BUILD.bat (CMake in container)
  • See CMAKE_FIX.md for detailed solutions

Problem: Build takes too long
Solution:
  • Normal first time (httplib.h preprocessing)
  • Subsequent builds will be faster (cached)
  • Docker caching helps on rebuilds

Problem: Docker not installed
Solution:
  • Download from: https://www.docker.com/products/docker-desktop
  • Or use DIRECT_BUILD.bat instead
  • See INSTALL_DOCKER.md for detailed steps
