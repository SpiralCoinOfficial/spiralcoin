OPTION 2: DIRECT NATIVE COMPILATION (Fastest for Windows)
──────────────────────────────────────────────────────────────────────────

Command:

    .\DIRECT_BUILD.bat

What it does:
  • Compiles directly with g++ (no CMake)
  • Skips CMAKE complexity
  • Produces native Windows binary

Time: 10-15 minutes (first build)
Reliability: ⭐⭐⭐⭐
Requirements: MinGW g++ (already have: C:\msys64\mingw64\bin\g++.exe)

═══════════════════════════════════════════════════════════════════════════

OPTION 3: DOCKER BUILD (Most Reliable)
──────────────────────────────────────────────────────────────────────────

Command:

    .\DOCKER_BUILD.bat

What it does:
  • Uses Docker container for isolated build
  • Guaranteed consistent environment
  • Pre-tested Dockerfile.dev

Time: 8-12 minutes (first), 1-2 minutes (cached)
Reliability: ⭐⭐⭐⭐⭐
Requirements: Docker Desktop installed

If Docker not installed:
  • Download: https://www.docker.com/products/docker-desktop
  • Or see: INSTALL_DOCKER.md in project folder

═══════════════════════════════════════════════════════════════════════════

OPTION 4: LINUX/WSL2 BUILD
──────────────────────────────────────────────────────────────────────────

Command (in WSL2 terminal):

    bash build.sh

What it does:
  • Uses native Linux tools
  • Fast compilation
  • Ideal for development

Time: 5-10 minutes
Reliability: ⭐⭐⭐⭐⭐
Requirements: WSL2 with Linux (Ubuntu recommended)

🧪 TEST YOUR BUILD

After building, test the RPC endpoint:

PowerShell:
    $response = Invoke-WebRequest -Uri "http://localhost:8545/rpc" `
      -Method POST `
      -Headers @{"Content-Type"="application/json"} `
      -Body '{"jsonrpc":"2.0","id":1,"method":"getblockcount","params":[]}'
    $response.Content

Or with curl:
    curl -X POST http://localhost:8545/rpc \
      -H "Content-Type: application/json" \
      -d '{"jsonrpc":"2.0","id":1,"method":"getblockcount","params":[]}'

Expected response:
    {"result": 1}
