QUICK SETUP (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

Step 1: Install Docker Desktop
────────────────────────────────────────────────────────────────────────

Go to: https://www.docker.com/products/docker-desktop

Click "Download for Windows" and run the installer.

During installation, make sure to check:
  ✓ Use WSL 2 instead of Hyper-V (optional but recommended)
  ✓ Install required Windows components

Restart your computer when prompted.


Step 2: Verify Docker is Working
────────────────────────────────────────────────────────────────────────

Open PowerShell or CMD and run:

    docker --version

You should see: "Docker version 27.x.x, build xxxxxx"


Step 3: Build SpiralCoin
────────────────────────────────────────────────────────────────────────

Run this command:

    docker build -f Dockerfile.dev -t spiralcoin:latest .

Wait 8-15 minutes for the build to complete.


Step 4: Start SpiralCoin
────────────────────────────────────────────────────────────────────────

Run this command:

    docker run -p 8545:8545 -v ./data:/app/data spiralcoin:latest

Your SpiralCoin daemon will start and listen on port 8545.


Step 5: Test Your Daemon (Optional)
────────────────────────────────────────────────────────────────────────

Open another terminal and run:

    curl -X POST http://localhost:8545/rpc ^
      -H "Content-Type: application/json" ^
      -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"getblockcount\",\"params\":[]}"

You should get: {"result": 1}

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Q: "Docker command not found"
A: Docker Desktop may still be starting. Wait 30 seconds and try again.

Q: Build takes very long
A: Normal! First build takes 8-15 minutes. Subsequent builds use cache and are faster.

Q: How do I know it's working?
A: You'll see "SpiralCoin RPC Server starting..." in the logs.
   Port 8545 will respond to RPC queries.

Q: How do I stop the daemon?
A: Press Ctrl+C in the terminal running the container.

Q: Where is my data?
A: In ./data/ folder (git-ignored for security)
