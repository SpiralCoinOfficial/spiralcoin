                            ONE-LINE BUILD
═══════════════════════════════════════════════════════════════════════════════

COPY AND PASTE THIS:

    .\AUTO_BUILD.bat

That's it. This command will:
  ✓ Auto-detect your system
  ✓ Try native build (if MinGW works)
  ✓ Fallback to Docker (if available)
  ✓ Install Docker (if needed)
  ✓ Build and run SpiralCoin
  ✓ No manual steps required

═══════════════════════════════════════════════════════════════════════════════
                            WHAT HAPPENS
═══════════════════════════════════════════════════════════════════════════════

Step 1: Check Docker
  IF Docker exists:
    → Build with Docker (fastest, most reliable)
    → Run daemon on port 8545
    → SUCCESS! Done!

  IF Docker NOT found:
    Continue to Step 2

Step 2: Check MinGW g++
  IF MinGW found and works:
    → Compile with g++
    → Create native binary
    → SUCCESS! Done!

  IF MinGW NOT found or broken:
    Continue to Step 3

Step 3: Install Docker
  → Opens Docker download page
  → You install Docker
  → Run script again
  → SUCCESS! Done!

═══════════════════════════════════════════════════════════════════════════════
                        THREE SCENARIOS
═══════════════════════════════════════════════════════════════════════════════

SCENARIO 1: You have Docker
  Time: 8-12 minutes
  Result: Docker daemon running SpiralCoin
  Status: ✓ WORKS

SCENARIO 2: You have MinGW but not Docker
  Time: 10-15 minutes
  Result: Native binary at build\spiralcoind.exe
  Status: ✓ WORKS

SCENARIO 3: You have neither
  Time: 5 minutes (install) + 8-12 minutes (build)
  Result: Docker daemon running SpiralCoin
  Status: ✓ WORKS GUARANTEED
