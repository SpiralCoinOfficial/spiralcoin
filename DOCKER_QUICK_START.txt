                        STEP 1: INSTALL DOCKER
═══════════════════════════════════════════════════════════════════════════════

1. Download Docker Desktop
   → https://www.docker.com/products/docker-desktop

2. Run installer (accept defaults)

3. Start Docker Desktop
   → Look for whale icon in system tray
   → Wait for "Docker is running"

4. Verify installation
   → Open CMD or PowerShell
   → Run: docker --version
   → Should show: Docker version 24.x.x or later

First Build (8-12 minutes):
  [1/8] FROM ubuntu:24.04                  ← Downloading Linux
  [2/8] RUN apt-get update                 ← Installing tools
  [3/8] COPY . /app                        ← Copying source

═══════════════════════════════════════════════════════════════════════════════
                      MANAGING DOCKER CONTAINER
═══════════════════════════════════════════════════════════════════════════════

Stop the daemon:
    Ctrl+C (in the terminal running Docker)
    or: docker stop spiralcoin

Start it again:
    docker start spiralcoin

View logs:
    docker logs spiralcoin
    docker logs -f spiralcoin (follow logs in real-time)

Remove container (frees space):
    docker rm spiralcoin

Remove image (frees more space):
    docker rmi spiralcoin:latest

Rebuild without cache (fresh compile):
    docker build --no-cache -f Dockerfile.dev -t spiralcoin:latest .

═══════════════════════════════════════════════════════════════════════════════
                    DOCKER TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Docker not found"
Solution:
  1. Install Docker Desktop
  2. Start Docker Desktop app
  3. Wait for whale icon to appear
  4. Retry: docker --version

Problem: "Cannot connect to Docker daemon"
Solution:
  1. Docker Desktop might not be running
  2. Start Docker Desktop app
  3. Look for whale icon in system tray
  4. Wait 30 seconds for startup
  5. Retry

Problem: "Out of disk space"
Solution:
  docker system prune --all
  This frees up cached images

Problem: Build takes too long
Solution:
  This is NORMAL first build!
  - Downloading Ubuntu: 2-3 minutes
  - Installing dependencies: 2-3 minutes
  - Compiling: 4-6 minutes
  - Total: 8-12 minutes is expected

  Subsequent builds use cache and are much faster!
