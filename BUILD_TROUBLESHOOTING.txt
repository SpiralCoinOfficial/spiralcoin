═══════════════════════════════════════════════════════════════════════════════
                          PROBLEM: g++ Not Found
═══════════════════════════════════════════════════════════════════════════════

If diagnostic shows: "g++ NOT FOUND"

SOLUTION A: Install MinGW (Recommended)
    1. Download MSYS2: https://www.msys2.org/
    2. Run installer
    3. In MSYS2 terminal, run:
       pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-g++
    4. Add to PATH: C:\msys64\mingw64\bin
    5. Verify: g++ --version

SOLUTION B: Use Docker Instead (Faster)
    1. Download Docker: https://www.docker.com/products/docker-desktop
    2. Run: .\DOCKER_BUILD.bat
    3. No local compiler needed!

═══════════════════════════════════════════════════════════════════════════════
                      PROBLEM: C++20 Compilation Fails
═══════════════════════════════════════════════════════════════════════════════

If diagnostic shows: "C++20 compilation failed"

SOLUTION: Upgrade MinGW g++
    1. Check version: g++ --version
    2. If < 11.0, upgrade:
       pacman -S mingw-w64-x86_64-gcc
    3. Verify: g++ --version should be 11.x or later
    4. Retry: .\DIRECT_BUILD.bat

═══════════════════════════════════════════════════════════════════════════════
                    PROBLEM: "Compiler Exited with Code 1"
═══════════════════════════════════════════════════════════════════════════════

If you see exit code 1 but no error message:

SOLUTION A: Check g++ is accessible
    1. Open CMD or PowerShell
    2. Run: where g++
    3. Should show: C:\msys64\mingw64\bin\g++.exe
    4. If not found, add to PATH

SOLUTION B: Run with Verbose Output
    The updated DIRECT_BUILD.bat now shows compiler output.
    Check build\compile.log for detailed errors.

SOLUTION C: Try Diagnostic
    .\DIAGNOSTIC_BUILD_TEST.bat
    This shows exactly what's wrong.

═══════════════════════════════════════════════════════════════════════════════
                  PROBLEM: Missing OpenSSL or Dependencies
═══════════════════════════════════════════════════════════════════════════════

If diagnostic or build mentions missing OpenSSL:

SOLUTION: Install OpenSSL in MinGW
    1. Open MSYS2 terminal
    2. Run: pacman -S mingw-w64-x86_64-openssl
    3. Verify: pkg-config --modversion openssl
    4. Retry build
