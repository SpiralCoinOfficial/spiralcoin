API Endpoints

  • /api/market/price — current SPRC price
  • /api/market/update — update SPRC price (POST)
  • /api/market/candles — OHLC candles for chart
  • /api/market/quotes — aggregated quotes (SPRC + BTC/ETH/USDT)
  • /api/market/stream/candles — SSE stream of candle updates (params: asset, vs, interval)
  • /api/market/stream/quotes — SSE stream of quotes/24h change
  • /api/supply — supply summary (founder, vault, total)
  • /api/supply/founder — founder wallet and balance
  • /api/supply/vault — supply vault wallet and balance
  • /api/supply/total — total supply
  • /api/mining — mine a block (POST)
  • /api/mining/transaction — add transaction (POST)
  • /api/wallet/balance/:address — wallet balance
  • /api/stats — chain stats
  • /health — server health
